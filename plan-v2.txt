DENTAL COURSE CALENDAR — PLAN v2
=================================

OVERVIEW
--------
A React SPA calendar covering a 2-year dental course (Sep 1, 2026 → Sep 1, 2028).
Anyone with access can view and edit the schedule. State persists in localStorage
via Redux Persist. No backend required.

TECH STACK
----------
- Vite + React 18 + TypeScript (strict mode)
- Redux Toolkit + redux-persist (localStorage)
- Tailwind CSS
- date-fns (date math)
- @dnd-kit/core (drag-and-drop to move sessions)
- uuid + @types/uuid (session IDs)
- ESLint + Prettier (code quality)

BEST PRACTICES
--------------
- Strict TypeScript throughout (no `any`)
- Typed Redux slices with RTK (createSlice, PayloadAction)
- Custom hooks for all store access (useAppDispatch, useAppSelector)
- Feature-based folder structure
- All components typed with React.FC or explicit props interfaces
- Utility functions are pure and fully typed
- Constants/enums for phase types and colors

FEATURES
--------
1. Calendar Views
   - Two-year overview (color-coded by phase)
   - Monthly detail view
   - Navigation between months/years

2. Session Display
   - Color-coded cells: preclinical (blue), clinical (green), vacation (amber), TBD (gray)
   - Session chips on day cells showing topic name

3. Session Modal (click any day)
   - View: date, phase, topic, notes, cases list
   - Edit: change title/notes/type
   - Delete session

4. Add Session
   - Click empty day → open "Add Session" modal
   - Set title, type, notes

5. Drag & Drop
   - Drag a session chip to another day to move it

6. Export / Import
   - Export button → downloads a `.json` file with all sessions + schema version
   - Import button → file picker reads JSON, shows confirmation dialog:
       · "Replace all sessions" — wipes current and loads imported
       · "Merge" — imported sessions are added; conflicts kept as-is
   - Exported file is versioned (schemaVersion field) for future compatibility

7. Sidebar Legend
   - Phase legend with colors
   - Quick-jump to phases

DATA MODEL (Redux)
------------------
sessions: {
  [id]: {
    id: string (uuid),
    date: "YYYY-MM-DD",
    title: string,
    phase: "preclinical" | "clinical_y1" | "clinical_y2" | "vacation" | "tbd",
    notes: string,
    cases: string[],
    color: string   // override per session (optional)
  }
}

ui: {
  currentYear: number,       // 2026 | 2027 | 2028
  currentMonth: number,      // 0-11
  selectedDate: string|null, // "YYYY-MM-DD"
  viewMode: "month" | "year"
}
